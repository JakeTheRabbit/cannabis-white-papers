Files: the figure source files listed in YOUR FILES (python figure modules `figs*.py` or `figs_*.json`). Text drawn inside the SVGs: titles, labels, notes, axis texts.

5. `PY _build/ste100/ste_units.py apply F --svg-text --dry-run`, then without `--dry-run`.
6. `PY _build/ste100/ste_verify.py check paper_<name>` for every paper that uses F: it must say `RESULT: PASS` (the figure structure must not change; only the text may).
Use the terms of the paper's rewritten text. Many labels are 1 to 4 words: keep them short; an approved word with the wrong meaning is still an error. Letters/units/symbols (pH, EC, VWC, kPa, mg/L, P1...) stay. Text inside a drawing does not need full sentences, but a note (a sentence) must follow the sentence rules.
